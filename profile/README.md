## 关于 IDCY Global

IDCY Global Network Inc.（亿达网络）是一家面向全球市场提供云计算、服务器及数据中心基础设施服务的技术企业。

我们围绕企业全球化部署持续建设计算、网络、IP、安全防护及数据中心资源，为网站、应用平台、跨境业务、SaaS 服务、互联网项目以及企业信息化系统提供稳定的基础设施支持。

目前，IDCY Global 的业务主要涵盖全球云服务器、独立服务器、多 IP 服务器、高防服务器、CN2 及国际网络、服务器托管、公有云服务等领域。

我们关注的不只是资源本身，而是计算、网络、交付和长期运维共同构成的服务能力。

# 服务理念

## 面向长期运行的基础设施

企业基础设施并不是一次性交付的产品。

从最初的服务器选择，到网络规划、业务上线、容量扩展、安全防护以及后续运维，每一个环节都会影响业务长期运行的稳定性。

IDCY Global 希望通过持续建设基础设施和服务体系，让客户可以更加专注于自身业务，而不是将大量时间投入到底层资源管理之中。

## 根据业务选择资源

不同业务对基础设施的要求并不相同。

面向亚洲用户的网站可能更关注网络延迟，全球化业务更关注节点覆盖，大型平台更关注计算能力，而高并发在线业务则可能同时需要带宽、安全防护和硬件性能。

因此，我们更倾向于根据实际业务需求选择适合的服务器、区域和网络，而不是用同一种产品解决所有问题。

## 稳定、透明、可持续

稳定的资源供应、清晰的产品信息和持续的技术服务，是基础设施业务长期合作的重要基础。

IDCY Global 将持续完善全球节点、服务器产品、网络资源和客户服务体系。
